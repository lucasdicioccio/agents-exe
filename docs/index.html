agents-exe

A handy LLM-agent tool, with a variety of calling and configuration modes so that the LLM adapts to your workflow rather than the opposite. An agent is a JSON file: an LLM endpoint and model, a system prompt, a directory of command-line tools, MCP servers, and helper agents it can prompt in turn. The same agent runs as a one-shot command, in a terminal UI, as an MCP server, or behind an HTTP server that keeps sessions across restarts.

agents-exe init                                              # write an agent.json and its tools directory
agents-exe run --agent-file agent.json --prompt "Hello!"     # one shot
agents-exe tui --agent-file agent.json                       # interactive terminal UI
agents-exe serve --agent-file agent.json                     # sessions over HTTP, durable, with a chat page
agents-exe mcp-server --agent-file agent.json                # every agent as an MCP tool

Tools are plain executables that describe themselves, MCP servers, or OpenAPI operations; helper agents are exposed to the model as functions the same way, so a root agent delegates to specialised ones and their results come back as tool results. Sessions are durable: a run can stop on a tool call that needs an external answer, a background call, or a message from another agent, and be resumed later, in the same process or another one.

The code is on GitHub at lucasdicioccio/agents-exe. It is a Haskell cabal project: the agents library, the agents-exe and agents-server executables, and agq, a small query tool over stored sessions.
